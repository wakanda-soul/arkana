# Arkana server

Node.js API behind the Arkana app: the deck engine, readings, the AI proxy for Ask Arkana, daily quotas and streaks, and the APK download page.

## What it does

- **Deck and readings.** Definitions of all 78 cards, draws, and the rules that look at card pairs, the dominant suit and the number of Major Arcana. Readings have seven parts.
- **Ask Arkana.** Chat answers are generated by an AI model called from `src/ai/oracleService.js`. Input is checked for prompt injection and requests for code before it reaches the model, and the answer is checked again on the way out. If the model fails or times out, the offline engine answers from the drawn card in the user's language (10 languages).
- **Dialogue log.** Every conversation is written to `data/*.jsonl` for review of injection attempts and errors. Logs never go to git.
- **Quotas and streaks.** Free spreads, the Seeker Oracle Pass, streak bonuses (+1/+2/+3/+5 on days 7/14/21/28, then +5 every 7 days) and streak repair.
- **Treasury attestation.** `GET /api/treasury` returns the treasury address with its offline Ed25519 signature. The app verifies it before paying.
- **Lookup table keeper.** `src/solana/lookupTable.js` keeps the Arkana Address Lookup Table filled with the vault, ORE Stake and pool accounts of current payment routes, so a payment fits into one transaction. It refreshes every 30 minutes.
- **APK hosting.** `/download` is the install page, `/arkana.apk` the latest build.

## API

| Method | Path | Purpose |
| :--- | :--- | :--- |
| `GET` | `/api/health`, `/api/version` | Status and current app build |
| `GET` | `/api/deck` | All 78 cards |
| `GET` | `/api/spreads` | Spread layouts |
| `GET` | `/api/clock-in/:wallet` | Clock-In status, streak, remaining free spreads |
| `POST` | `/api/clock-in` | Daily draw, streak update, quota refill |
| `POST` | `/api/spread/consume` | Use a free spread or record a paid one |
| `POST` | `/api/reading` | Draw cards and write the reading |
| `POST` | `/api/chat` | Ask Arkana |
| `GET` | `/api/treasury` | Treasury address and attestation |
| `GET` | `/api/lookup-table` | Arkana lookup table address |
| `POST` | `/api/offering`, `/api/subscription/activate`, `/api/streak/repair` | Record paid actions |
| `POST` | `/api/seeker/status` | Seeker Genesis holder status |
| `POST` | `/api/solana-rpc` | RPC proxy for the app |
| `*` | `/api/admin/*` | Economy config and dialogue logs, requires `ARKANA_ADMIN_TOKEN` |

## Configuration

`.env` in this folder (never committed):

| Variable | Meaning |
| :--- | :--- |
| `PORT` | API port, default 3001 |
| `ARKANA_ADMIN_TOKEN` | Token for `/api/admin/*` (header `x-admin-token`). Admin endpoints are off without it |
| `ARKANA_ALT_KEYPAIR` | Keypair that pays for the lookup table, default `~/.config/solana/id.json` |
| `ARKANA_ALT_KEEPER` | `off` disables the lookup table keeper |
| `SOLANA_RPC_URL` | RPC for the keeper, default publicnode |

## Running

```bash
npm install
npm start
```

In production it runs as the systemd unit `arkana.service`. `scripts/sync_release.sh` (cron, every 2 minutes) installs new APKs from GitHub releases.
