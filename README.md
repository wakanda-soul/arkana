# Arkana

A crypto tarot app for Solana Mobile and the Seeker phone. Arkana is the reader: she draws from a 78-card deck built around blockchain archetypes, answers questions about the cards, and keeps a daily ritual with streaks. Payments in SKR burn part of the supply and lock part of the value as staked ORE for the user.

[arkana.icu](https://arkana.icu) · [Download the Android APK](https://arkana.icu/arkana.apk) · [Download page](https://arkana.icu/download) · [Releases](https://github.com/wakanda-soul/arkana/releases)

## What is in the app

- **The deck.** 22 Major Arcana (Genesis Block, Validator, Hard Fork, Liquidation, ATH and others) and 56 Minor Arcana in four suits: Nodes, Liquidity, Protocols and Assets. Users only ever see the Arkana deck.
- **Readings.** Cards are drawn with local RNG. The server checks card pairs, the dominant suit and how many Major Arcana fell, then writes a reading in seven parts: the story, hidden forces, what strengthens you, what weakens you, advice, a warning and the final omen.
- **Ask Arkana.** A chat where Arkana answers a question through a drawn card. Answers are generated by an AI model on the Arkana server. If the model is unavailable, a built-in engine answers from the card's meaning in any of the 10 app languages.
- **Daily Clock-In.** One card a day, a streak counter and bonus spreads for streaks: +1 on day 7, +2 on day 14, +3 on day 21, +5 on day 28 and every 7 days after that. Bonus spreads stay on the account until used.
- **Codex.** All 78 cards with upright and reversed meanings, available offline.
- **Languages.** English by default, plus Chinese, Hindi, Spanish, Arabic, French, Bengali, Portuguese, Russian and Indonesian. The language is chosen on first launch.
- **Wallet.** Phantom, Solflare or Seed Vault through Mobile Wallet Adapter. The session survives app restarts.

## Where the money goes

Every payment ends the same way:

- **33%** of the price in SKR is burned on-chain (SPL `Burn`).
- **33%** goes to the Arkana treasury.
- **34%** is swapped to ORE at the market rate through Jupiter and deposited into the user's own tranche in the Arkana ORE Vault.

A user without SKR can pay in SOL. The app then swaps SOL to exactly 66% of the price in SKR (burned and sent to the treasury as above) and swaps SOL worth 34% of the price to ORE for the tranche. The result is identical to an SKR payment.

The user approves a payment once. It is one transaction when it fits into Solana's 1232-byte limit, which the Arkana lookup table (see below) makes the normal case. If a Jupiter route is unusually large, the payment goes out as two transactions in the same wallet prompt.

### ORE Vault

`programs/arkana-ore-vault` is a Solana program written with [Steel](https://github.com/regolith-labs/steel).

- Each user gets one tranche per day. The first payment of the day opens it and pays its rent. Later payments that day top it up at no extra rent.
- All tranche ORE is staked in the ORE Stake protocol (`stakecNP3FpiExZPCgZfqRgumVzi6dNqnfrjwXyTgeH`) by the vault's PDA. ORE Stake yield is pulled into the vault and shared between tranches in proportion to their size.
- Users can claim their yield at any time.
- After 365 days a tranche is harvested: the ORE principal goes to the Arkana treasury, all unclaimed yield goes to the user, and the tranche account is closed with its rent returned to the user. The user or the treasury can trigger it; the payout always goes to the tranche owner.
- `SyncStake` is a permissionless crank that pulls ORE Stake yield and stakes any principal that is not staked yet.

A top-up settles the yield on the old balance before adding new ORE, so fresh deposits never earn yield for time they were not in the vault.

## Running it

### Server

Node.js 18 or newer.

```bash
cd arkana-server
npm install
npm start
```

The API listens on port 3001. In production Caddy serves https://arkana.icu in front of it (see `arkana-server/deploy/Caddyfile`). Without an AI model binary configured the server still works: readings and chat fall back to the built-in engine.

The lookup table keeper starts with the server when a Solana keypair is present at `~/.config/solana/id.json` (or `ARKANA_ALT_KEYPAIR`). That key only pays rent for the table. Set `ARKANA_ALT_KEEPER=off` to disable it.

### App

```bash
cd arkana-app
npm install
npx expo run:android   # a phone with USB debugging, or the Seeker
```

Mobile Wallet Adapter needs a real Android device with a wallet app installed. Emulators work for the UI only.

### Program

Solana CLI with `cargo build-sbf`:

```bash
cd programs/arkana-ore-vault
cargo build-sbf
```

### Vault tests

The vault is tested in [LiteSVM](https://github.com/LiteSVM/litesvm) against a snapshot of mainnet: the real ORE Stake program binary, the ORE mint, the ORE Stake treasury and the Arkana vault accounts. The test deposits, tops up a daily tranche, pulls ORE Stake yield, claims it, moves the clock 366 days and harvests, checking every balance on the way.

```bash
cd programs/arkana-ore-vault && cargo build-sbf
cd tests && npm install
npm run fixtures   # snapshot the mainnet accounts (Solana CLI)
npm test
```

## Releases and versions

Every push to `main` builds a signed APK in GitHub Actions and attaches it to the `v1.0.0-beta` release together with `version.json`. The download server picks up new builds on its own.

The version comes from `arkana-app/release.json`: `version` holds major.minor, and the patch number counts builds since `firstBuild`. To start a new minor version, bump `version` and set `firstBuild` to the next CI run number.
